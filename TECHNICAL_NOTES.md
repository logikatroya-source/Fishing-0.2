# Технический отчёт — GamePilot Fishing 0.1

**Дата:** 2026-11-14.

## Архитектура

- `fishing/model.py`: проверяемые настройки, ROI, файловые операции с атомарной записью.
- `fishing/windows.py`: Windows HWND, PID, область клиента и контроль фокуса.
- `fishing/vision.py`: обработка индикаторов, ROI-motion, template matching.
- `fishing/engine.py`: чистый автомат состояний (получает View/время, возвращает команды, не выполняет IO).
- `fishing/input.py`: pynput-контроллер с повторной проверкой цели, атомарным освобождением мыши и watchdog.
- `fishing/profiles.py`: переносимый профиль для устройств с тем же игровым разрешением.
- `fishing/ui.py`: PySide6, высококонтрастный интерфейс, обновление без накопления устаревших кадров, мастер разметки.
- `main.py`: точка входа.

## Ограничения MVP

- Достоверного распознавания поклёвки из пользовательского видеозаписи пока нет; ROI motion needs tuning (threshold).
- Мини-игра контролируется простым предиктивным правилом по смещению маркера. На другом разрешении или при иной цветовой схеме нужна новая калибровка.
- Использование шаблона результата добровольное. Без него «пойманных рыб» = 0, а «неясных» будет расти.
- Автоматический переход между рыболовными точками не реализован.
- Не используются мини-карта, карта местности, AI-модель, внутриигровые API, пакетный сниффинг или инъекции.
- Windows EXE собирается GitHub Actions; в текущей среде не запускался Windows GUI, так как нет Windows и нет установленного PySide6.

## Инварианты безопасности

1. Нельзя начать управление без готовой шкалы, шаблона маркера и точки заброса.
2. Каждый новый mouseDown валидирует HWND, PID, foreground и размеры клиентской области.
3. Потеря фокуса вызывает паузу и отпускание кнопки.
4. F8 сигнализирует аварийную остановку и вызываeт освобождение мыши из обработчика горячей клавиши.
5. Отдельный watchdog освобождает кнопку при пропаже обработки кадров.
6. Кнопка после смены места не используется без новой разметки точки воды.
7. Неопределённый результат сбора не засчитывается как рыба.
8. После предела забросов GamePilot не перемещает персонажа самостоятельно.

## Тестирование

Тесты pytest: модель настроек, сериализация, экспорт/импорт профиля и защита от небезопасных имён ZIP, motion detection, CV-мачинг, зелёная шкала, логика состояния и таймеров, блокировка неопознанной шкалы, управление кнопкой по координатам маркера, аварийный стоп, автоматическая пауза при потере фокуса.

**Не протестировано:** реальный Windows-захват, клавиатурный hook, ввод в клиент, калибровка по игровым кадрам, GUI в браузере/Qt и успешная поимка рыбы в игре. Ни один тест не должен интерпретироваться как гарантия работы в игровом клиенте.
