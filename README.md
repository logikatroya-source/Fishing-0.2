# GamePilot Fishing 0.1 — стационарная рыбалка

**Назначение:** отдельная Windows-программа для управления **одной рыболовной точкой** в собственном тестовом клиенте. Без карты, перемещения, распознавания озёр, сетевого сервера и ИИ. Программа не считывает память игры и не внедряется в процесс.

## Что реализовано

- Подключение к **конкретному игровому окну** (выбор из списка Windows, проверка HWND и PID).
- Захват **клиентской области**, а не всего рабочего стола; анализ OpenCV, обработка последних кадров без очереди устаревших изображений.
- Разметка точек и областей непосредственно на кадре с масштабированием.
- Три режима: «Наблюдение», «Помощь с мини-игрой», «Полный цикл».
- В полном цикле: удержание кнопки для заброса → ожидание визуальной поклёвки → подсечка → управление нажатием/отпусканием при вываживании → проверка результата → новая попытка.
- Отдельно считаются **забросы**, **подтверждённые уловы** и **неопределённые результаты**.
- Остановка после 10 попыток по умолчанию, затем ручная смена места. При наличии обученного образца результата дополнительно ограничивается количество подтверждённых рыб.
- F3 — запуск/пауза, F4 — стоп-кадр для калибровки, F8 — аварийная остановка с немедленным отпусканием мыши (при работающем глобальном обработчике).
- Контроль фокуса и размера игрового окна, watchdog против зависшего удержания кнопки.
- Настройки и образцы хранятся в `%LOCALAPPDATA%\GamePilotFishing\`; экспорт/импорт ZIP-профиля для другого ноутбука **с тем же разрешением и масштабом интерфейса**.

## Очень важно: что НЕ подтверждено

**Этот релиз не протестирован в твоём Windows-клиенте.** 31 тест проверяет логику, но не распознавание реальной поклёвки и индикатора. До получения кадров настоящей рыбалки не обещаем, что он автоматически вытащит первую рыбу. Прототип требует визуальной калибровки и исправлений по реальным записям.

Исчезновение мини-игры **не доказывает улов**. Если не обучен уникальный визуальный признак успешного результата, программа не увеличивает счётчик пойманной рыбы — показывает «Неясно» и ограничивается счётчиком забросов.

Управление мини-игрой предполагает, что **удержание левой кнопки сдвигает маркер вправо, отпускание — влево**. Это соответствует описанию механики Albion, но может отличаться в конкретном тестовом клиенте. На официальном сервере использование автоматизации может нарушать правила игры.

## Первая настройка — рекомендованный порядок

### 1. Окно игры

1. Открой тестовый клиент в **оконном режиме без рамки (Borderless)**.
2. Запусти `GamePilotFishing.exe`.
3. В разделе «Подключение» выбери **окно игры**, нажми «Подключить».
4. Выбери **«Наблюдение — без кликов»**. Убедись, что на превью именно игра, а не GamePilot.

### 2. Точка заброса

1. Поставь персонажа у воды, удочка должна быть доступна персонажу.
2. В панели нажми **① «Точка заброса»** и кликни на нужную воду **на превью**.
3. Точка должна попадать в игровую поверхность, не на интерфейс и не на мини-карту.

### 3. Область поплавка

1. Самостоятельно забрось удочку в игре, чтобы поплавок был виден.
2. Нажми **F4** (заморозить полученный кадр).
3. В GamePilot нажми **② «Поплавок / поклёвка»** и мышью выдели **небольшой** участок вокруг поплавка (например, 35×35 пикселей оригинального изображения). Большая область воды снижает чувствительность.
4. Нажми F4 ещё раз, чтобы вернуться к живому изображению.

### 4. Области мини-игры (ключевая часть)

1. Сыграй в рыбалку **вручную** и, когда появляется шкала вываживания, **нажми F4** для стоп-кадра.
2. На замороженном кадре разметь **③ «Вся шкала мини-игры»** — прямоугольник вокруг всей горизонтальной шкалы.
3. Разметь **④ «Зелёная зона»** — только безопасный участок, куда должен попадать маркер. Это горизонтальная зона, а не весь интерфейс.
4. Разметь **⑤ «Маркер шкалы»** — небольшой, но отличимый фрагмент вокруг движущегося значка. Лучше захватить текстуру/контур значка, но не всю зелёную полоску.
5. Опционально поймай рыбу вручную, нажми F4 и разметь **⑥ «Сообщение об улове»**. Выделяй только событие, которое **исчезает после улова**; постоянная иконка инвентаря не подходит.
6. Нажми «Сохранить профиль».

### 5. Проверка в три этапа

1. **Наблюдение:** убедись, что при появлении мини-игры диагностика показывает `Шкала: ДА`, а `Маркер` — высокое сходство; без активной мини-игры должно быть `Шкала: нет`.
2. **Помощь:** ты забрасываешь и подсекаешь вручную, а бот лишь нажимает/отпускает кнопку для удержания значка в зелёной зоне. Наблюдай первые попытки.
3. **Полный цикл:** убедись, что F8 работает, запусти режим «Полный цикл» и переключись в игру. Начни с 1–2 попыток в настройках; затем можно увеличить до 10.

### 6. Смена места

После 10 **забросов** (или установленного лимита подтверждённых рыб) GamePilot прекращает выдавать команды. Ты самостоятельно перемещаешь персонажа, нажимаешь **«Новое место ловли»**, заново выбираешь **точку заброса**, затем запускаешь цикл. Не нужно заново выделять маркер и шкалу, если интерфейс игры не изменился.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| F3 | Начать выбранный режим / пауза |
| F4 | Стоп-кадр для калибровки (только вне автоматического цикла) |
| F8 | Аварийный STOP; освобождает удерживаемую кнопку |

> Команда F8 останавливает **новые действия GamePilot**, но не может гарантированно отменить уже принятое игрой действие. Глобальные клавиши должны корректно обрабатываться Windows; если обработчик недоступен, автоматическое управление не разрешается.

## Сборка Windows EXE через GitHub

1. Создай приватный GitHub-репозиторий (или очисти отдельный репозиторий для рыбалки).
2. Распакуй ZIP; загрузи **содержимое** в корень репозитория, включая `.github/workflows/build-windows.yml`.
3. **Actions → Build GamePilot Fishing Windows EXE → Run workflow**.
4. После успешной проверки и сборки скачай артефакт `GamePilotFishing-Windows`; внутри `GamePilotFishing.exe`.
5. Python на другом Windows-ПК не требуется; игру, однако, нужно установить отдельно.

## Локальные тесты для разработчика

```powershell
python -m pip install -r requirements.txt pytest
python -m pytest tests -q
python main.py
```

### Лицензии и происхождение

Код в этом ZIP разработан специально для GamePilot Fishing и **не содержит скопированного кода сторонних fishing-ботов**. Мы использовали только опубликованные описания игровой механики как ориентир. Убедись, что автоматизация разрешена в твоём собственном тестовом клиенте.
